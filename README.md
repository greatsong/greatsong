# 송석리 (Song Sukree)

저는 송석리이며, 당곡고등학교 정보 교사입니다. 2005년부터 서울의 고등학교에서 정보를 가르쳤고, 데이터·인공지능 교육과 교육과정 연구에 참여하며 교과서를 집필했습니다. 서울대학교 사범대학에서 데이터와 AI를 2020년부터 2026년 8월까지 강의했고, 코딩하는 교사 커뮤니티 '쪼랩'을 운영합니다.

Song Sukree is an Informatics (computer science) teacher at Danggok High School in Seoul, South Korea, and an author on data and AI education.
